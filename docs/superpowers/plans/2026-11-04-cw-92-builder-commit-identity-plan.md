# CW-92 plan: author and push ticket branch commits as the builder user

Spec: [2026-11-04-cw-92-builder-commit-identity-design.md](../specs/2026-11-04-cw-92-builder-commit-identity-design.md). All paths below are under `agent-team/`. Do not push as the builder in tests: use a local bare remote and a fake `gh`.

1. `scripts/git.sh` (new, executable): shaped like `gh.sh`. Role from `AGENT_GH_ROLE`, login from `project_config.py login <role>` (exit 2 with a `git.sh:` line on an unknown role). Empty login or no role: `exec git "$@"`. Otherwise token from `env -u GITHUB_TOKEN -u GH_TOKEN gh auth token -u <login>` (missing: exit 2, `git.sh: no gh login for <login>; ...`, run no git). Read `id` and `name` with `gh api user` using that token. Export `GIT_AUTHOR_*` and `GIT_COMMITTER_*` (email `<id>+<login>@users.noreply.github.com`, name falls back to the login). Export `GIT_SH_TOKEN`. Run `git -c credential.helper= -c 'credential.helper=!f() { ... }; f' "$@"` where the helper answers only `get` with `username=x-access-token` and `password=$GIT_SH_TOKEN`. For `push`: exit 2 if the push remote's URL is not https; exit 2 naming the commit, with the rebase fix command, if any commit in `git rev-list HEAD --not --remotes=origin` has an author email other than the builder's.
2. `scripts/test_git_sh.py` (new): one table-driven test in the pattern of `test_gh_sh.py` (fake `gh` on PATH, temp `PROJECT_MD`, temp repo plus local bare remote). Rows per the spec's § Tests. Assert no token in `git config --list` or `.git/config`. Plus one `git.sh credential fill` check returning the fake token.
3. Docs (prose, no tests): `.claude/skills/ship-loop/SKILL.md` § Team mode **GitHub users** (one sentence), `docs/agents/github-auth.md` (replace the "Commits and pushes keep" sentence, add the owner `user.email` Set up step, add the `git.sh var GIT_AUTHOR_IDENT` check to Verify).
4. Verify: `python3 -I -m pytest -q agent-team/scripts`, `shellcheck install.sh tag-release.sh agent-team/scripts/*.sh`, and `python3 -I -m pytest -q agent-team/scripts/test_root_links.py agent-team/scripts/test_install.py` (the new script must ship).
5. Open the PR, closeout docs, docs check, code review, security review, per ship-loop § Team mode.
