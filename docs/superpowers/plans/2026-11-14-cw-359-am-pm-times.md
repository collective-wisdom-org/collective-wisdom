# CW-359 plan: 12-hour am/pm times

Spec: [../specs/2026-11-14-cw-359-am-pm-times-design.md](../specs/2026-11-14-cw-359-am-pm-times-design.md)

Rule: hour `h`, minute `m` show as `{h % 12 or 12}:{m:02d} {am|pm}`.

1. `agent-team/scripts/dashboard/page/app.js` and `mods/agent-gantt/hooks/format.ts`: `clock(ms)` returns the rule in local time. Export `clock` from `format.ts` already; export it from `app.js` if a test needs it. Update `app.test.js` strings (`09:05`, `03:04`) and add one table-driven test per helper (12:00 am, 12:30 am, 9:05 am, 12:00 pm, 11:59 pm).
2. New `agent-team/scripts/clock12.py` with `clock12(dt)`; one table-driven test `test_clock12.py`.
3. `cos_state.py` `t()` -> `clock12` without the space (`2:05pm`); `cos_idle_check.py` `hhmm()` -> `2:05 pm UTC`; `release_notes.py` -> `Merged YYYY-MM-DD 9:00 am UTC.`; `agent_usage.py` window -> `... 9:00 am UTC to ... 5:30 pm UTC`. Update the existing tests that assert old text. Update the `Merged ... HH:MM UTC` sentence in `agent-team/docs/superpowers/README.md`.
4. Run: `python3 -I -m pytest -q agent-team/scripts` and `node --test agent-team/scripts/dashboard/*.test.ts agent-team/scripts/dashboard/page/app.test.js mods/agent-gantt/hooks/*.test.ts`.
