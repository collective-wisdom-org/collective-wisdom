## collective-wisdom agent team

The agent team (its skills, subagents and scripts, installed from collective-wisdom at `~/.collective-wisdom`) runs only in a repo that has `docs/agents/project.md`. In a repo without that file the team is not running: do not start its skills (such as chief-of-staff, ship-loop or kickoff-feature) and do not run its scripts there. The one exception: `set up this repo` and `start the team` may still run there, and only to do the setup (chief-of-staff `setup.md`).
