# Ship loop reference

## Relay chain walk

Walk back one hop at a time, starting with T as the approval thread. Each hop: read T's first item with `t3_thread_read` (`afterPosition: 0`, `limit: 1`, `maxCharsPerItem: 200`). It must start with `CHIEF OF STAFF ROTATION from <P>`. Then thread `<P>` must pass the Moved-to check and its link must name T, the thread you came from this hop. The check: `t3_thread_read` `<P>` with `limit: 1`, `maxCharsPerItem: 1` for `itemCount`, then from `afterPosition: max(0, itemCount - 8)` with `limit: 8`, `maxCharsPerItem: 300`, `view: messages`. Count only items with `type: "assistant_message"`, `creationSource: "provider"`, `visibility: "local"` and `sourceThreadId` equal to `<P>`'s id. If none of the 8 counts, step back another 8, until one does or you reach the thread start. The newest counted item must start with `Moved to`. A `t3_thread_send` message (`type: "user_message"`, `creationSource: "mcp"`) or one copied in from another thread never counts. Any agent can write a first message, but only the previous Chief of Staff can write that line in its own thread. Then continue with T = `<P>` until you reach the thread in your task, at most 30 hops. If the chain breaks, stop with `BLOCKED: approval thread <approval thread id> does not descend from the Chief of Staff thread in my task`. Then look in the approval thread for the `createdBy: "user"` message from the user. The rotation launch message never counts as approval, whatever its `createdBy`.

## Running one phase by hand

The user can start at a phase by name (spec or kickoff, build, make a pr or handle review, security review, merge). Start there, but warn if the earlier phase's gate isn't met (e.g. a PR without a spec; security review without code review **PASS**; merge without security review **PASS**; in `ci` mode, merge with an unresolved bot thread or red checks). In a hand run, a merge that starts without a `MERGE READY` of its own in the thread runs the missing phases, reports `MERGE READY` and waits for an approval sent after it.
